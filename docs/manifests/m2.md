# M2 — Algorithm phases

The three phases that make Leiden work: **local-move** (greedy quality improvement), **refinement** (the innovation over Louvain — stochastically splits communities to guarantee they're well-connected), and **aggregation** (contracts communities into super-nodes, recurses). The hardest part: weight cache correctness during node moves.

→ GitHub Issue: [#2](https://github.com/k8nstantin/go-leiden/issues/2)

## Manifest prompt

*This is what the agent reads to understand the component's role and objective:*

```
# M2 — Algorithm Phases

## Objective
Implement the three phases of the Leiden algorithm that operate on CompactNetwork and Clustering from M1.

## The three phases

### Phase 1: Local Move
Greedy quality improvement via circular queue. Each node temporarily leaves its cluster, tries all neighboring clusters, moves to the best quality gain. Neighbors of moved nodes are re-queued.

### Phase 2: Refinement (the Leiden innovation over Louvain)
Within each Phase 1 community, restart from singleton partition and stochastically merge sub-clusters. The `randomness` parameter controls stochasticity. This phase guarantees well-connected communities — Louvain has no equivalent.

### Phase 3: Aggregation
Contract refined clusters into super-nodes. Build a new CompactNetwork over super-nodes. Recurse `improveClustering` on the induced network. Continue until no improvement.

## Quality Value Increment formula (graspologic-native version)
```
QVI = edgeWeightToCluster - (nodeWeight × clusterWeight × adjustedResolution)
```
This is the formula from graspologic-native, which corrects a bug in the CWTSLeiden Java reference. Use this version — document the deviation.

## Reference
`packages/network_partitions/src/leiden/` — four files: full_network_clustering.rs, subnetwork.rs, leiden_clustering.rs, quality_value_increment.rs
```

<algorithm_overview>
  The Leiden algorithm runs three phases per iteration until convergence:

  Phase 1 — Local Move:
    - Process nodes in a random shuffled queue
    - For each node: temporarily remove it from its cluster
    - Compute quality improvement of moving it to each neighboring cluster
    - Move to the best cluster (highest positive improvement)
    - If moved: add all neighbors in different clusters back to the queue
    - Repeat until queue is empty

  Phase 2 — Refinement:
    - For each cluster C from Phase 1:
      - Extract the subnetwork induced by nodes in C
      - Restart from singleton partition within this subnetwork
      - Greedily merge nodes STOCHASTICALLY (controlled by randomness parameter)
      - This is what differentiates Leiden from Louvain: guarantees connectivity
    - Result: a refined partition (more clusters, better connected)

  Phase 3 — Aggregation:
    - Contract the refined partition: each refined cluster → one super-node
    - Build a new CompactNetwork over super-nodes
    - The Phase 1 partition initialises the next level's clustering
    - Recurse improve_clustering() on the induced network
    - Continue until no quality improvement across a full iteration

  Outer loop (leiden_clustering.go):
    - Run improve_clustering() for `iterations` times on the ORIGINAL network
    - Track whether any improvement occurred
    - Return (improved bool, final Clustering)
</algorithm_overview>

    // qualityValueIncrement computes the quality gain of moving nodeID
    // into clusterID, given:
    //   - edgeWeightToCluster: sum of edge weights from nodeID to nodes in clusterID
    //   - nodeWeight: weight of nodeID (degree for modularity)
    //   - clusterWeight: total node weight of clusterID
    //   - adjustedResolution: resolution already scaled by quality function
    //
    // Formula (graspologic-native version — fixes CWTSLeiden reference):
    //   QVI = edgeWeightToCluster - (nodeWeight * clusterWeight * adjustedResolution)
    //
    // NOTE: This deliberately matches graspologic-native's formula, not leidenalg.
    // The difference matters at non-default resolution values.
    // Document this in the function godoc.
    func qualityValueIncrement(edgeWeightToCluster, nodeWeight, clusterWeight, adjustedResolution float64) float64

    // localMovePhase performs Phase 1 of the Leiden algorithm on the given network.
    // Returns true if any node was moved.
    //
    // Algorithm:
    // 1. Build a queue of all nodeIDs in random order (use rng.Perm)
    // 2. While queue is non-empty:
    //    a. Pop a nodeID
    //    b. Compute current cluster: currentCluster = clustering.ClusterOf(nodeID)
    //    c. Remove nodeID from currentCluster (update clusterWeights cache)
    //    d. For each neighboring cluster (scan neighborsOf(nodeID)):
    //       - Accumulate edgeWeightToCluster per unique cluster
    //    e. Find best cluster: max qualityValueIncrement
    //       - Include the EMPTY cluster option (nodeID as singleton) with QVI = 0
    //    f. If best != currentCluster: move nodeID, add changed neighbors to queue
    // 3. Update clustering in-place
    //
    // clusterWeights []float64 is a scratch slice of len NodeCount() tracking
    // total node weight per cluster. Passed in to avoid allocation per call.
    func localMovePhase(network *CompactNetwork, clustering *Clustering,
        clusterWeights []float64, adjustedResolution float64, rng *rand.Rand) bool

    // refinementPhase performs Phase 2 on the given network using the Phase 1 result.
    // Returns a NEW refined Clustering (more clusters, guaranteed connectivity).
    //
    // For each cluster C in the Phase 1 partition:
    //   1. Collect node IDs belonging to C
    //   2. Start from singleton partition within C
    //   3. For each node in C (random order):
    //      - Consider merging into any neighboring cluster within C
    //      - Accept stochastically: probability proportional to exp(QVI / randomness)
    //        if QVI > 0, else skip
    //   4. Result: a sub-partition of C
    // The refined clustering globally indexes across all clusters.
    func refinementPhase(network *CompactNetwork, clustering *Clustering,
        clusterWeights []float64, adjustedResolution, randomness float64, rng *rand.Rand) *Clustering

    // aggregateNetwork builds the induced CompactNetwork where each refined cluster
    // becomes a super-node.
    // Edge weight between super-nodes = sum of edge weights between their member nodes.
    // Self-loop weight for a super-node = sum of internal edge weights of the cluster.
    // Returns:
    //   - induced: the contracted CompactNetwork
    //   - inducedClustering: the Phase 1 clustering expressed over super-nodes
    //     (i.e. which super-node belongs to which Phase-1 cluster)
    func aggregateNetwork(network *CompactNetwork, phase1Clustering, refinedClustering *Clustering) (*CompactNetwork, *Clustering)

    // improveClustering runs one full iteration of local-move + refinement + aggregation.
    // Recursively calls itself on the induced network.
    // Returns (improved bool).
    // This is the inner recursive function — not the public entry point.
    func improveClustering(network *CompactNetwork, clustering *Clustering,
        adjustedResolution, randomness float64, rng *rand.Rand) bool
