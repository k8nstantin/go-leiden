## What the agent builds

# M5 — Test Suite, Benchmarks, Validation

## Objective
Write the test suite that validates correctness against known outputs, benchmarks performance, and fuzzes the public API for panics.

## Validation tests
- **Karate club graph** (Zachary 1977, 34 nodes, 78 edges): classic benchmark. At resolution=1.0, modularity should be > 0.35.
- **Two planted partitions** (2 × 10-node cliques, weak bridge): should produce exactly 2 communities. Deterministic with seed=42.
- **Quality score reproducibility**: ComputeQuality(result.Partition) == result.Quality within 1e-9.
- **HierarchicalLeiden max cluster size**: all final clusters ≤ MaxClusterSize.

## Benchmarks
- 100 nodes, 1k nodes, 10k nodes
- 10k-node graph must complete in under 5 seconds
- Report allocs/op

## Fuzz
- `FuzzLeiden`: arbitrary byte input → must never panic
- Specifically targets weight cache invariants in localMovePhase

## Done
`go test ./...` passes, `go test -bench=. shows sub-5s at 10k nodes`, `go test -fuzz=FuzzLeiden -fuzztime=30s` completes without panic.
