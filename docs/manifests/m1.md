## What the agent builds

# M1 — Core Data Structures

## Objective
Implement the foundational data structures for go-leiden. Nothing else in the library can be built without these types.

## What to build

### CompactNetwork
A CSR (Compressed Sparse Row) adjacency list — the same layout as graspologic-native's `CompactNetwork` struct. Cache-optimised for the local-move phase inner loop.

```
nodes[i].neighborStart → index into neighbors[] where node i's list begins
neighbors[nodes[i].neighborStart .. nodes[i+1].neighborStart] → all neighbors of i, sorted ascending by id
```

Constructor takes `[]Edge`, handles: duplicate edge merging (sum weights), self-loop separation, undirected expansion (A→B adds B as neighbor of A and A as neighbor of B).

### Clustering
A node→clusterID mapping. Simple `[]int` with helpers. Starts as singleton (each node in its own cluster). Supports: SetCluster, ClusterOf, Clone, Renumber (makes IDs contiguous 0..k-1), ToMap (to string→int for API output).

### Edge
```go
type Edge struct { Source, Target string; Weight float64 }
```

### Errors
Sentinel errors for invalid inputs (empty edges, zero/negative weights, etc.)

    type Edge struct {
        Source string  // arbitrary node label
        Target string
        Weight float64 // must be > 0
    }

    // CompactNetwork is a CSR adjacency list — cache-optimised for the local-move inner loop.
    // Layout: nodes[i].neighborStart = start index in neighbors slice for node i.
    //         nodes[i+1].neighborStart = exclusive end (last node uses len(neighbors)).
    //         neighbors for each node are sorted ascending by id.
    // Matches graspologic-native's CompactNetwork struct exactly.
    type CompactNetwork struct { /* unexported fields */ }

    // NewCompactNetwork builds from edges. Rules:
    // - Undirected: A→B adds B to A's neighbors AND A to B's neighbors
    // - Duplicate edges (same pair): merge by summing weights
    // - Self-loops (Source==Target): go to totalSelfLinksWeight, NOT neighbors
    // - Node IDs assigned in first-encounter order across all edges
    // - Neighbors sorted ascending by ID after construction
    // - Returns error: empty edges, weight <= 0, empty node label
    func NewCompactNetwork(edges []Edge) (*CompactNetwork, error)

    func (n *CompactNetwork) NodeCount() int
    func (n *CompactNetwork) EdgeCount() int
    func (n *CompactNetwork) NodeLabel(id int) string
    func (n *CompactNetwork) NodeID(label string) (int, bool)
    func (n *CompactNetwork) neighborsOf(id int) []compactNeighbor // unexported, direct slice
  </file>
