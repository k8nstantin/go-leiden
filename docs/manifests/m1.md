# M1 — Core data structures

The foundation. Implements `CompactNetwork` (a CSR adjacency list — the cache-optimised graph representation used by the algorithm's inner loop), `Clustering` (node→community mapping), `Edge` types, and error sentinels. Everything else in the library builds on these types.

→ GitHub Issue: [#1](https://github.com/k8nstantin/go-leiden/issues/1)

## Manifest prompt

*This is what the agent reads to understand the component's role and objective:*

```
# M1 — Core Data Structures

## Objective
Implement the foundational data structures for go-leiden. Nothing else in the library can be built without these types.

## What to build

### CompactNetwork
A CSR (Compressed Sparse Row) adjacency list — the same layout as graspologic-native's `CompactNetwork` struct. Cache-optimised for the local-move phase inner loop.

```
nodes[i].neighborStart → index into neighbors[] where node i's list begins
neighbors[nodes[i].neighborStart .. nodes[i+1].neighborStart] → all neighbors of i, sorted ascending by id
```

Constructor takes `[]Edge`, handles: duplicate edge merging (sum weights), self-loop separation, undirected expansion (A→B adds B as neighbor of A and A as neighbor of B).

### Clustering
A node→clusterID mapping. Simple `[]int` with helpers. Starts as singleton (each node in its own cluster). Supports: SetCluster, ClusterOf, Clone, Renumber (makes IDs contiguous 0..k-1), ToMap (to string→int for API output).

### Edge
```go
type Edge struct { Source, Target string; Weight float64 }
```

### Errors
Sentinel errors for invalid inputs (empty edges, zero/negative weights, etc.)

## Reference
`packages/network_partitions/src/network/compact_network.rs` in graspologic-native.
```

<deliverables>
  Create the following files:

  <file path="network.go">
    Package: leiden

    <type name="Edge">
      // Edge is a weighted undirected connection between two labeled nodes.
      // Source and Target are arbitrary string labels (e.g. "auth.Login", "file.go").
      // Weight must be > 0. Negative or zero weights are rejected by the constructor.
      type Edge struct {
          Source string
          Target string
          Weight float64
      }
    </type>

    <type name="compactNode">
      // compactNode is one entry in the CompactNetwork.nodes slice.
      // neighborStart is the index into CompactNetwork.neighbors where
      // this node's adjacency list begins. neighborEnd is derived as
      // nodes[i+1].neighborStart (or len(neighbors) for the last node).
      type compactNode struct {
          weight        float64
          neighborStart int
      }
    </type>

    <type name="compactNeighbor">
      // compactNeighbor is one entry in the CompactNetwork.neighbors slice.
      // Neighbors for each node are stored contiguously and sorted ascending by id.
      type compactNeighbor struct {
          id     int
          weight float64
      }
    </type>

    <type name="CompactNetwork">
      // CompactNetwork is a cache-optimised CSR (Compressed Sparse Row) adjacency
      // representation of an undirected weighted graph.
      //
      // Memory layout:
      //   nodes[i].neighborStart = index into neighbors where node i's list begins
      //   nodes[i+1].neighborStart = exclusive end (for last node: len(neighbors))
      //   neighbors[nodes[i].neighborStart : nodes[i+1].neighborStart] = all neighbors of i
      //
      // This layout is identical to graspologic-native's CompactNetwork struct.
      // It minimises cache misses during the local-move phase inner loop.
      type CompactNetwork struct {
          nodes                  []compactNode
          neighbors              []compactNeighbor
          totalSelfLinksWeight   float64
          totalEdgeWeight        float64 // sum of all edge weights (excluding self-links)
          nodeLabels             []string // index → original label
          labelIndex             map[string]int // original label → index
      }
    </type>

    <constructor name="NewCompactNetwork">
      // NewCompactNetwork builds a CompactNetwork from a slice of Edges.
      //
      // Rules:
      // - Duplicate edges (same Source+Target pair) are merged: weights are summed.
      // - Self-loops (Source == Target) are stored separately in totalSelfLinksWeight
      //   and are NOT added to the neighbors list.
      // - The graph is treated as undirected: edge (A→B, w) adds B as neighbor of A
      //   AND A as neighbor of B, each with weight w.
      // - Node ordering: nodes are assigned integer IDs in the order they are first
      //   encountered across all edges (by Source then Target).
      // - Neighbors for each node are sorted ascending by neighbor ID after construction.
      // - Returns error if any edge has Weight <= 0 or if Source == Target == "".
      //
      // Node weight (used by quality functions):
      //   For Modularity: node weight = sum of all incident edge weights (node degree)
      //   For CPM: node weight = 1.0 (uniform)
      // The constructor stores the Modularity node weight by default.
      // Quality functions can override node weights when needed.
      func NewCompactNetwork(edges []Edge) (*CompactNetwork, error)
    </constructor>

    <methods>
      func (n *CompactNetwork) NodeCount() int
      func (n *CompactNetwork) EdgeCount() int  // number of unique undirected edges
      func (n *CompactNetwork) NodeLabel(id int) string  // id → original label
      func (n *CompactNetwork) NodeID(label string) (int, bool)  // label → id
      // neighbors returns the contiguous neighbor slice for node id.
      // Direct slice access — no allocation.
      func (n *CompactNetwork) neighborsOf(id int) []compactNeighbor
    </methods>
  </file>

  <file path="clustering.go">
    Package: leiden

    <type name="Clustering">
      // Clustering maps each node (by integer ID) to a cluster ID.
      // Cluster IDs are arbitrary non-negative integers — not necessarily contiguous.
      // The zero-value Clustering is NOT valid; use newSingletonClustering or newClustering.
      type Clustering struct {
          membership []int  // index = nodeID, value = clusterID
          nextCluster int   // next unused cluster ID (for new cluster creation)
      }
    </type>

    <constructor name="newSingletonClustering">
      // newSingletonClustering creates a Clustering where each node is its own cluster.
      // nodeCount must match CompactNetwork.NodeCount().
      // This is the standard starting state for the Leiden algorithm.
      // cluster IDs are 0..nodeCount-1 (node i starts in cluster i).
      func newSingletonClustering(nodeCount int) *Clustering
    </constructor>

    <constructor name="newClustering">
      // newClustering creates a Clustering from an existing membership slice.
      // membership[i] = cluster ID for node i.
      // Returns error if any cluster ID is negative.
      func newClustering(membership []int) (*Clustering, error)
    </constructor>

    <methods>
      func (c *Clustering) ClusterOf(nodeID int) int
      func (c *Clustering) SetCluster(nodeID, clusterID int)
      func (c *Clustering) NodeCount() int
      func (c *Clustering) ClusterCount() int  // number of distinct cluster IDs
      func (c *Clustering) NewCluster() int    // allocates and returns next cluster ID
      // ToMap converts to map[nodeLabel]clusterID using the network's label mapping.
      func (c *Clustering) ToMap(n *CompactNetwork) map[string]int
      // Clone returns a deep copy.
      func (c *Clustering) Clone() *Clustering
      // Renumber remaps cluster IDs to 0..k-1 in order of first appearance.
      // Call before returning results to callers.
      func (c *Clustering) Renumber()
    </methods>
  </file>
