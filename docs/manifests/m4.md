# M4 — Public API

## Objective
Expose a clean, idiomatic Go API over the M1+M2+M3 internals. Set up the go.mod and write the README.

## API surface

```go
// Primary entry point
func Leiden(edges []Edge, opts Options) (Result, error)

// Hierarchical — recursively sub-clusters communities over MaxClusterSize
func HierarchicalLeiden(edges []Edge, opts HierarchicalOptions) ([]HierarchicalCluster, error)

// Quality scoring only (no clustering)
func Modularity(edges []Edge, communities map[string]int, resolution float64) float64
```

## Key behaviours
- `Options.Trials > 1`: run algorithm N times, return best quality result
- `Options.Seed > 0`: fully deterministic output
- `Result.Partition`: cluster IDs are always 0..k-1 (contiguous, renumbered)
- All input validation returns typed errors, never panics

## Module
```
module github.com/openpraxis/go-leiden
go 1.22
// zero external dependencies
```

## Reference
`packages/pyo3/src/lib.rs` in graspologic-native — the three public Python-facing functions mirror our Go API.
