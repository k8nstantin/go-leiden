# M3 — Quality functions

**Modularity** (measures edge density vs random expectation) and **CPM** (Constant Potts Model — measures density against a threshold). Includes the resolution scaling formula from graspologic-native, which corrects a bug in the original CWTSLeiden reference implementation.

## Manifest prompt

*This is what the agent reads to understand the component's role and objective:*

```
# M3 — Quality Functions

## Objective
Implement Modularity and CPM quality functions, including the resolution scaling that feeds into the Phase 1 QVI calculation.

## Modularity
Measures how much within-community edge density exceeds random expectation.

Resolution scaling (graspologic-native corrected formula):
```
adjustedResolution = resolution / (2.0 × (totalEdgeWeight + totalSelfLinksWeight))
```
Node weight = degree (sum of incident edge weights).

## CPM (Constant Potts Model)
Measures internal density vs a threshold.

Resolution scaling: `adjustedResolution = resolution` (no scaling).
Node weight = 1.0 (uniform).

## ComputeQuality
An exported function that scores a complete partition. Used for: reporting final result quality, comparing Trials runs, and tests.

## Reference
`packages/network_partitions/src/quality.rs` and `resolution.rs` in graspologic-native.
```

<quality_functions>
  <modularity>
    // Modularity measures how much the fraction of edges within communities
    // exceeds what would be expected by chance in a random graph.
    //
    // For a partition C over graph G with total edge weight m:
    //   Q = (1/2m) * sum_{ij} [A_ij - (k_i * k_j) / 2m] * delta(c_i, c_j)
    //
    // Where:
    //   A_ij = edge weight between i and j (0 if no edge)
    //   k_i  = degree of node i (sum of incident edge weights)
    //   m    = total edge weight (totalEdgeWeight in CompactNetwork)
    //   delta(c_i, c_j) = 1 if i and j are in same cluster, else 0
    //
    // Resolution scaling for the algorithm (graspologic-native formula):
    //   adjustedResolution = resolution / (2.0 * (totalEdgeWeight + totalSelfLinksWeight))
    //
    // Node weight for Modularity = sum of incident edge weights (degree).
    // This is what NewCompactNetwork stores by default.
  </modularity>

  <cpm>
    // CPM (Constant Potts Model) measures internal density vs a resolution threshold.
    //
    // For a partition C:
    //   H = sum_c [e_c - resolution * n_c * (n_c - 1) / 2]
    //
    // Where:
    //   e_c = sum of edge weights within cluster c
    //   n_c = number of nodes in cluster c
    //
    // Resolution scaling for CPM:
    //   adjustedResolution = resolution  (no scaling — used directly)
    //
    // Node weight for CPM = 1.0 (uniform).
    // The algorithm must use uniform node weights when UseModularity=false.
  </cpm>
</quality_functions>

<deliverables>
  <file path="quality.go">
    Package: leiden

    // QualityFunction identifies which quality function to use.
    type QualityFunction int
    const (
        Modularity QualityFunction = iota
        CPM
    )

    // computeAdjustedResolution returns the resolution value to use in
    // qualityValueIncrement calls, scaled appropriately for the quality function.
    //
    // For Modularity:
    //   adjustedResolution = resolution / (2.0 * (network.totalEdgeWeight + network.totalSelfLinksWeight))
    //   Special case: if totalEdgeWeight == 0, return 0 (avoids division by zero)
    //
    // For CPM:
    //   adjustedResolution = resolution (no scaling)
    func computeAdjustedResolution(network *CompactNetwork, resolution float64, qf QualityFunction) float64

    // nodeWeightsFor returns the node weight slice appropriate for the quality function.
    // For Modularity: returns the degree-based weights already in CompactNetwork.
    // For CPM: returns a slice of all 1.0 values (uniform).
    // The returned slice must not be modified by callers.
    func nodeWeightsFor(network *CompactNetwork, qf QualityFunction) []float64

    // ComputeQuality computes the quality score of a clustering under the given function.
    // Used for reporting the final result quality and for the trials comparison.
    //
    // This function is exported — used in the public API and in tests.
    func ComputeQuality(network *CompactNetwork, clustering *Clustering, resolution float64, qf QualityFunction) float64
  </file>

  <file path="quality_test.go">
